# Petcare — modelo veterinário 01

Demonstração de site institucional para clínicas veterinárias criada para o portfólio da Guará Agency.

**Prévia prevista:** https://guaraagency-julio.github.io/modelo-pet-1/

## Estrutura

- `index.html`: página principal e conteúdo em português brasileiro.
- `styles.css`: identidade visual, responsividade e transições.
- `site.js`: menu mobile, abas de serviços, depoimentos e formulário demonstrativo.
- `favicon.svg`: ícone.
- `.github/workflows/pages.yml`: deploy automático via GitHub Actions.

## Recursos

- Hero fotográfico, serviços, apresentação da clínica, depoimentos ilustrativos, FAQ, equipe fictícia e contato.
- Layout responsivo, redução de movimento, navegação por teclado, tags Open Graph e SEO.
- Formulário que **gera uma mensagem local para copiar**, sem envio a servidor.
- Textos, membros da equipe, depoimentos e informações de contato **fictícios, para demonstração**.

Fotos de demonstração foram referenciadas do acervo Pexels. Para um projeto real, substituir por fotos da clínica ou arquivos licenciados para o cliente e verificar se todos os links continuam acessíveis.

## Como publicar

O workflow publica automaticamente a versão estática da branch `main` no GitHub Pages, desde que a opção **Settings → Pages → Build and deployment → GitHub Actions** esteja habilitada para o repositório. O deploy pode ser inspecionado na aba Actions do GitHub.

## Personalização antes de entregar a um cliente

Substituir marca e imagens, nome e registros dos profissionais, serviços reais, horário, endereço, contatos e avaliações. Integrar a solicitação de agendamento a WhatsApp ou plataforma escolhida. Não utilizar depoimentos e qualificações fictícios como afirmações reais.
